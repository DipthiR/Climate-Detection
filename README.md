# Climate-Detection
# 🌦 Climate Checker (No API Key Needed)

This is a simple Python script that:

- Detects your current city using your IP address
- Shows the current weather for that city
- Does **not** require any API key

## 🛠 Requirements

- Python 3
- `requests` module

Install `requests` if needed:
pip install requests
